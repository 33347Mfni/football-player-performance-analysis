# Football Player Performance Analysis

## Project Overview

This project analyzes football player performance data to identify the key factors associated with player ratings and match performance.

The analysis combines data cleaning, exploratory data analysis (EDA), correlation analysis, and predictive modeling to extract meaningful insights from a large football dataset.

## Dataset

* **Original dataset:** 173,587 rows and 48 columns
* **Modeling dataset:** 173,334 rows and 47 features
* **Target variable:** `player_rating`
* **Analysis focus:** Player performance, match outcomes, and factors associated with player ratings

## Key Analysis

The project includes:

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Statistical and correlation analysis
* Analysis of player performance metrics
* Analysis of team results
* Feature relationships with `player_rating`
* Predictive modeling

## Key Findings

Several performance-related variables showed notable relationships with player ratings.

The strongest correlations with `player_rating` included:

* **Goals:** 0.493
* **Goal Difference:** 0.471
* **Ground Duels Won:** 0.413
* **Touches:** 0.409
* **Shots on Target:** 0.408

The `team_result` variable was also transformed into numerical categories representing:

* Loss = 0
* Draw = 1
* Win = 2
